雨课堂助手使用教程

工具版本

1.21.5

功能介绍

AI雨课堂助手是一个为雨课堂提供辅助功能的工具，可以帮助你更好地参与课堂互动。

项目仓库：GitHub

脚本安装：GreasyFork

工具栏按钮说明

  • 习题提醒：切换是否在新习题出现时显示通知提示（蓝色=开启）。
  • 课件浏览：查看课件与题目页面，提问可见内容。
  • AI 解答：向 AI 询问当前题目并显示建议答案。
  • 自动作答：切换自动作答（蓝色=开启）。
  • 设置：配置 API 密钥与自动作答参数。
  • 使用教程：显示/隐藏当前教程页面。

自动作答

  • 在设置中开启自动作答并配置延迟/随机延迟。
  • 需要配置 LLM API 密钥。
  • 答案来自 AI，结果仅供参考。
  • 如果刷新中断了 AI 思考，可在当前题目页、活动题目卡片、题目列表或 AI 面板点击“AI 强制作答”。
  • AI 分析后会显示结构化答案编辑框；确认或修改后可提交。已过截止时间的题目会先确认，再走强制补交。
  • 设置中的“刷新后恢复”“过期自动补交”“扫描未作答题”相互独立，默认关闭；恢复仅处理本地已经记录的题目。

刷新恢复说明

  • 脚本会按课程保存题目的排队、作答中和失败状态，不保存 API 密钥或 AI 原文。
  • 开启“刷新后恢复已排队/被中断的 AI 作答”后，刷新页面会重新开始未完成的 AI 请求；同一题不会并发提交。
  • 开启“刷新后自动强制补交已过期题目”后，过期的恢复任务会调用补交接口；建议只在明确需要时开启。
  • “自动扫描当前课程中未作答题目”可能包含旧课件题，默认关闭；不需要时保持关闭。

AI 解答

  1. 点击设置（）填入 API Key。
  2. 每个 AI Profile 可单独设置 Temperature（0–2）；留空时使用模型默认值，不会发送该参数。
  3. 点击 AI 解答（）后会对“当前题目/最近遇到的题目”询问并解析。

课堂提醒、桌面路由与亮屏

  • 设置中可以分别控制新题、新一轮弹幕、重复弹幕达到跟发条件、题组发布、课件发布、其他发布、下课以及自动作答的每个阶段；系统通知、页面弹窗和提示音也可单独关闭。
  • 打开或翻阅旧课件不会触发课件发布提醒；发布类提醒只提示，不会自动作答或提交。
  • 在“课堂运行”中打开“重复弹幕自动跟发”后，最近 7 条弹幕内同一文本出现 3 次会跟发 1 条；相邻弹幕间隔达到 60 秒算新一轮，每轮最多 2 条，同一文本每轮只跟发一次。提醒设置还可以提示新一轮开始，以及同文弹幕第 3 次出现、即将跟发的时刻。功能默认关闭。
  • 右下角活动题目卡片右上角的“×”只隐藏卡片，不删除题目、不取消自动作答；题目完成或离开活动状态后，关闭记录会自动清理。
  • 脚本只运行桌面端功能。若雨课堂跳转到 /m/v2，脚本会自动改写为对应桌面路径；若服务器仍强制跳回手机版，请在浏览器中启用“桌面版网站”。
  • 系统通知需由浏览器或篡改猴授予权限；脚本不会自动请求或修改系统通知权限。
  • “课堂保持亮屏”仅在可见的课堂页防止自动熄屏，无法阻止手动锁屏、后台冻结或系统省电策略。

注意事项

1) 仅供学习参考，请独立思考；

2) 合理使用 API 额度；

3) 答案不保证 100% 正确；

4) 自动作答有一定风险，谨慎开启。
