# 雨课堂助手（Frank fork）

课堂提醒、课件浏览、AI 辅助分析与可配置的作答流程。继承自 [ZaytsevZY/yuketang-helper-auto](https://github.com/ZaytsevZY/yuketang-helper-auto)，MIT 许可。

当前版本：**1.22.0**。源码入口为 `ykt-helper/src/index.js`。

## 安装

1. 在 Chrome / Edge 安装 [Tampermonkey](https://www.tampermonkey.net/)，允许用户脚本运行。
2. [安装当前版本](https://raw.githubusercontent.com/Frank-678/yuketang-helper-auto/main/release/ykt-helper.user.js)。版本固定副本位于 [release/ykt-helper-1220.user.js](release/ykt-helper-1220.user.js)。
3. 登录雨课堂，在助手设置中填写自己的模型接口、API Key 和模型 ID。
4. 初次升级后检查自动作答、提交方式和快答配置，再按自己的需求开启。

旧的 1.21.7 成品保留在 `release/`，可用于回滚。启用一份脚本即可，避免同时运行旧版与新版。

## 答案与提交

本地草稿、AI 建议、服务器已确认答案分别保存。草稿编辑会自动保存到当前设备，保存本地不会标记为已提交。AI 期间的人工修改或手动提交优先。

自动答案处理有三档：

| 模式 | 行为 |
|---|---|
| 正常提交，必要时强制补交 | 题目开放时正常提交；明确结束时尝试补交 |
| 只正常提交 | 结束后保留本地，不自动补交 |
| 只生成并保存本地 | 保留候选与草稿，等待手动处理 |

题目列表和 AI 面板均可编辑答案、选择处理方式、采用 AI 建议。强制补交仍由平台决定是否接受；只有服务器逐题确认成功才显示成功。

网络中断、超时、无效响应或“已经作答”冲突会保留答案并显示待核实。可复用已观察到的课件请求同步；服务器未返回结果时，需要在官方页面重新打开相应课件。不会把结果未知当成成功，也不会循环盲目重交。

没有可用 API Key 时会提示配置问题，不再把固定 A 或“略”当成 AI 答案自动提交。

## 快答与复核

- **强制开启**：始终使用所选快答配置。
- **强制关闭**：使用常规模型，不因时间紧而偷偷启用快答。
- **按时间自动**：按浏览器本地时间，在所设时间点前 1 分钟到后 10 分钟使用快答。

快答控制模型与顺序，提交权限独立。未设置有效快答配置时使用常规模型，并在诊断中记录实际模型。剩余时间用于调度与请求预算；不限时题不会被视为立即过期。

可选择独立模型复核。常规作答优先提交前复核；快答可先提交，再保留复核建议。复核提出不同答案时，修改仍通过统一补交流程核实，不保证服务器允许改答。

## 课堂运行

- 题目数据、草稿与任务按账号及课堂隔离；长 ID 保持字符串。
- 刷新后恢复轻量任务和已有候选。上次提交结果未知时先核实，不重新调用模型碰运气。
- 重复事件不会重复提醒；历史时间线安静恢复近期未完成任务。
- 自动进入只选择正在上课的课堂。10 秒跳转等待期间，用户操作会取消自动跳转；官方点击不被劫持。
- 自动进入的课堂可单独默认使用自动作答；工具栏暂停会停止后续自动提交。
- 连接断开后可重新连接；后台课堂只有取得相应课件与题目数据后才会处理，不会把别的课堂当成当前题。
- 手机版入口会尝试转换为桌面路由。保持亮屏仅在可见课堂页、且浏览器支持时生效。

## 提醒、弹幕与课件

提醒事件和系统通知、页面卡片、声音均可单独配置。当前正在查看的课件发布静默，其他新发布仍可提醒。

弹幕默认关闭。开启后，当前课堂 30 秒内凑齐 7 条有效他人弹幕，取最高频完整文本；并列取最新出现的文本。一轮最长 60 秒，至多发出 2 条，同文每轮一次。输入框有内容或正在编辑时跳过，以实际出站帧判断发出；发出与服务器确认分开记录。

支持 OCR、翻译、多页提问和 PDF 导出。相同 OCR 请求会合并，多页缺图时明确报错；PDF 可导出整份课件或选中页面，单页失败会提示页码。MathJax 和 PDF 工具按需加载，避免阻塞脚本的首次启动。

## 开发与验证

需要 Node.js 24（CI 验证版本）和 npm：

```bash
cd ykt-helper
npm ci
npm test
```

修改源码后运行 `npm run release` 同步发布副本。`npm test` 先构建实际安装产物，再运行模块测试和 JSDOM 组合回归。生成文件为 `ykt-helper/dist/ykt-helper-1220.user.js`，发布时同步到 `release/ykt-helper-1220.user.js` 和 `release/ykt-helper.user.js`。

隔离测试不代表真实课堂全环境验收。服务器接口/改答权限、真实图片 CORS、Android/Tampermonkey、系统权限、后台冻结与模型答案正确率仍取决于实际环境。当前不提供服务器无人值守程序、手机号密码自动登录、整份考试试卷的通用提交或动态二维码处理。
